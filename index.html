                      How FocusFlow works

                      Backup & Restore

                      Backup Data downloads a portable FocusFlow file. Restore Backup can move that data back into FocusFlow on a compatible browser/device. Restoring replaces the current local planner data, so FocusFlow asks for confirmation first.

                      Appearance & Accessibility

                      Settings can enlarge text, increase contrast, reduce visual density, or reduce motion. These preferences change presentation only—your tasks, goals, notes, and progress stay untouched.

                      Progress Intelligence

                      FocusFlow looks for a few useful patterns in your real activity, such as consistent habits, aging open tasks, overdue work, completed actions, and Focus sessions. It does not score your worth or invent data.

                      Voice Capture

                      Tap the microphone, speak naturally, then review the text before adding it. Voice uses browser/device speech recognition when available. If it is unsupported or permission is denied, typing remains fully available.

                      Goals & Milestones

                      Start with an outcome and one next action. Add milestones only when they help. Goal progress updates from completed milestones, and the next action can surface on Home.

                      Calendar

                      Schedule now includes a simple month view. Tap a day to see its agenda. Dated tasks appear automatically beside scheduled events, so you do not enter the same information twice.

                      Type naturally

                      For tasks, FocusFlow can recognize simple timing words such as today, tomorrow, or a weekday, plus phrases like urgent/high priority. You can still edit details yourself.

                      Start simple

                      Use the large capture box. No planner setup is required. Add what is on your mind and FocusFlow keeps it in the system.

                      Power when you need it

                      Advanced tools stay available without getting in the way of starting.

                      Command Center

                      Your home base. It brings together what needs attention without making you hunt through sections.

                      Quick Add

                      Capture a Task, Goal Action, or Note from one line. Fast capture comes before detailed setup.

                      Daily Brief

                      Now shows urgent work, Next shows upcoming or important work, and Later keeps lower-urgency items visible.

                      Next Best Action

                      FocusFlow considers urgency and priority to suggest one useful action. It is guidance, not a requirement.

                      Tasks

                      Add priorities and optional due dates. Use Tomorrow to defer a task one day without rebuilding it.

                      Connected Actions

                      Add an optional website/resource. Open Resource takes you there in one tap; FocusFlow does not log in or depend on that service.

                      Schedule

                      Keep dated and timed commitments visible. A meeting or resource link can be attached when useful.

                      Goals

                      Give a goal a next action. That action can surface in the Command Center so goals turn into something you can do.

                      Habits & Streaks

                      Mark today's habit complete. Daily checkboxes reset while completion history is retained for streaks.

                      Focus

                      Use the shared Focus Timer. Moving between FocusFlow sections does not create a second timer.

                      Progress & Review

                      FocusFlow uses real completed activity to summarize progress. Plan Ahead adds an important action back into Tasks.

                      Notes

                      Use Brain Dump for thoughts that do not need structure yet. Your wording stays exactly as you enter it.

                      Motivational Guidance

                      On limits encouragement to a few meaningful moments; Minimal reduces it further; Off removes it.

                      Language

                      The interface is localization-ready. Only languages that pass wording and layout QA will be offered.

                      Saving & Privacy

                      Core planner data is stored locally in your browser on this device. No ProgressMint account or paid cloud service is required.

                      Backup

                      Backup Data downloads a JSON copy of your FocusFlow data. Keep backups somewhere you control.

                      Good to know

                      Open Resource only opens a link you chose to save. FocusFlow does not store outside-service passwords. Browser/device behavior can vary. If you clear browser site data without a backup, locally stored planner data may be removed.
