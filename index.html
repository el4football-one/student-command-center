🎓 Add a grade to an assignment

  1. After an assignment is completed, or once its due date arrives, open Assignments.
  2. Tap Add grade beside that assignment.
  3. Choose Percentage, Points earned / possible, or Letter grade (A, B, C, D, or F).
  4. For points, the app calculates the percentage automatically. Letter grades are not converted to percentages because school grading scales differ.
  5. The entered grade stays attached to the assignment and can appear in Parent Updates. Grades do not award XP.

👪 Grades in Parent Updates

  1. Parent Updates include current numerical class results when entered in the planner.
  2. Recently entered assignment grades are listed with the class and assignment name.
  3. Only student-entered grades are shown; the app does not estimate missing grades.
  4. The update clearly states that planner grades are not the school's official gradebook.

🗓️ Upcoming Schedule on Schedule page

  1. The Upcoming Schedule section is all-inclusive, not extracurricular-only.
  2. It includes classes, assignment due dates, exams, activities, jobs, and personal commitments.
  3. Items are grouped by day and ordered by time.
  4. Assignment items are labeled Assignment Due so due dates are easy to spot.

📅 Day-at-a-glance Schedule

  1. The Unified Student Schedule groups everything by date.
  2. Each day card contains that day's classes, assignments, exams, activities, jobs, and personal commitments.
  3. Items inside each day are sorted by time so you can scan the day from morning to evening.
  4. Today's card is visually highlighted.
  5. The Dashboard Upcoming Schedule shows the next 7 days. The Schedule page keeps four rolling weeks available in collapsible sections.

🗓️ Upcoming Schedule

  1. The Dashboard's Upcoming Schedule is all-inclusive and limited to the next 7 days.
  2. It combines upcoming classes, assignments, exams, extracurriculars, jobs, and personal commitments.
  3. Items are grouped by day and sorted by time so you can see each day at a glance.
  4. Completed assignments and exams are not shown as upcoming.
  5. Open Schedule for the full day-in-the-life view.

🧠 Exams use class + date

  1. Choose Add Exam / Quiz.
  2. Select the class, choose today or a future date, and add optional notes.
  3. No separate exam title is required.
  4. The exam appears in Exams and automatically on the Unified Student Schedule.

📅 One unified Schedule

  1. Schedule is the single day-in-the-life view for the app.
  2. Classes are managed in Academics but automatically appear in Schedule.
  3. Assignments, exams, activities, sports, clubs, jobs, and personal commitments also appear there.
  4. Use Normal Day, Shortened Day, or No School overrides to change which class times appear on specific dates or ranges.

📆 Date rules

  1. All new dates must be today or later.
  2. Past dates cannot be entered for assignments, exams, activities, classes, projects, or other scheduled items.
  3. This helps prevent accidental backdating.

🧠 Add & edit exams

  1. Open Exams or choose Add Exam / Quiz from Quick Add.
  2. Enter title, subject, date, and notes, then save.
  3. The exam appears in Exams and the overall Schedule.
  4. Tap Edit to change it later.

🏫 Classes in the overall Schedule

  1. Classes saved in Academics automatically appear in Daily and Weekly Schedule views.
  2. Use Schedule → School Day Schedule to mark a date Shortened Day or No School.
  3. Shortened Day uses each class's saved alternate times.
  4. Select a date range to apply a shortened schedule to several days or a full week.
  5. Restore Normal to return those dates to standard class times.

👆 One-hand navigation

  1. Every major student area is available directly from the bottom navigation.
  2. Swipe the bottom navigation left or right to see Today, Schedule, Assignments, Academics, Exams, Study, Progress, Parent, Help, and Settings.
  3. No core student feature requires landscape mode or a hidden menu.
  4. Landscape may also show the expanded left menu, but it contains the same destinations.

🎓 Academics & class schedule

  1. Open Academics from the bottom navigation.
  2. Use Add course, or Dashboard → Quick Add → Add Class / Course.
  3. Enter the class, teacher, room, semester/term, meeting days, and normal start/end time.
  4. If the school uses a shortened or alternate day, name it and enter its alternate start/end time.
  5. Tap Edit on any class when a semester, teacher, room, day, or time changes.
  6. Your saved class schedule automatically feeds the Unified Student Schedule.

🧠 Exams & quizzes

  1. Open Exams directly from the bottom navigation.
  2. Tap Add exam, or use Dashboard → Quick Add → Add Exam / Quiz.
  3. Select the class, choose today or a future date, and add optional notes.
  4. Use Edit if exam information changes.
  5. Exam records use the same completion workflow as assignments.

📱 Portrait phone navigation

  1. Portrait is designed for everyday one-handed phone use.
  2. The Student Command Center / ProgressMint Studios identity remains visible in the mobile header.
  3. Use the five bottom tabs for the most-used areas.
  4. Swipe the bottom navigation to reach Exams, Academics, Parent Updates, Help, Settings, and every other major feature.
  5. Landscape may provide an expanded left menu, but the same major features remain directly available from the bottom navigation.

📱 iPhone landscape navigation

  1. When an iPhone is held horizontally, the full left navigation remains available.
  2. If the screen height is short, swipe up or down inside the left menu itself to reveal the remaining items.
  3. The main page can scroll separately from the navigation menu.

📱 Mobile navigation & Academics

  1. In portrait phone view, use the five bottom tabs for the most common areas.
  2. Tap ☰ All Features at the top for the complete navigation list.
  3. The full mobile menu includes Exams, Academics, Parent Updates, Help, and Settings as well as the main sections.
  4. Landscape and wider screens provide the expanded left navigation, but all features remain accessible in portrait.

✏️ Edit an assignment

  1. Open Assignments.
  2. Tap Edit on the assignment you want to change.
  3. Update the type, title, subject, due date, or notes.
  4. Tap Save changes.
  5. Editing does not change completion XP unless you delete or change the assignment's completed state.

🏆 Level trophies

  1. Each level from 1–10 has its own trophy distinction.
  2. Your current trophy stays visible on the Dashboard beside your Level.
  3. When you reach a new level, its celebration plays first and the new trophy becomes your Dashboard distinction.
  4. Open Progress to see earned trophies in the Trophy Case and upcoming locked levels.
  5. Trophies represent planning, focus and completed effort; they do not change XP or grades.

🏆 Rewards, XP & celebrations

  1. XP is earned for planning, completed work, and finished Study sessions — not for grades.
  2. Assignments, Study sessions, project milestones, and planning milestones can trigger a short celebration.
  3. Level-up celebrations are larger than regular milestones.
  4. Celebrations are visual only; saving, XP, timers, and navigation still work even if an animation does not play.
  5. Turn celebrations off in Settings if you prefer fewer visual effects. Reduce Motion is respected.

🏠 Dashboard & Quick Add return

  1. Student Command Center opens on the Dashboard each time the app is launched.
  2. Use Quick Add from the Dashboard to start a supported action.
  3. After saving an Assignment, Exam / Quiz, or Schedule Activity / Job started through Quick Add, the app returns to the Dashboard.
  4. Study and Parent Updates remain open while you are actively using them; use the app navigation when finished.

⚡ Parent Updates — Quick Add

  1. From Today, tap Quick Add.
  2. In Quick Actions, choose Open Parent Updates.
  3. The app opens Parent Updates directly.
  4. Review the update before using the email/share action.

⚡ Quick Add & Quick Actions

  1. Quick Add is a Dashboard shortcut.
  2. Tap it to open Quick Actions.
  3. Choose the action you want: Assignment, Exam / Quiz, Schedule Activity / Job, Study Session, or Parent Updates.
  4. Schedule opens directly into Add Activity. Study opens directly to Study, and Parent Updates opens directly to Parent Updates. Assignment and Exam / Quiz entry fields are available immediately in Quick Actions.

✅ Completed Assignments

  1. Tap the completion circle on an active assignment.
  2. It moves to Completed Assignments and receives its completion credit.
  3. Completed assignments remain visible for 7 days.
  4. Tap Mark incomplete during that period to return one to Active.
  5. After 7 days the individual record clears, but earned XP/progress remains credited.

⏱️ Study timer & XP

  1. Open Study or choose Study Session from Quick Actions.
  2. Select a preset or custom session length.
  3. Start the timer. A running session continues when you leave and return to the app.
  4. Pause only when you want the session to stop counting down.
  5. Complete the session to receive the displayed XP credit.

👪 Parent Updates — Navigation

  1. Open Parent Updates from the labeled Parent Updates navigation/control.
  2. Review the student information, progress and schedule information shown there.
  3. Use only the sharing/update controls presented by the app.
  4. The app does not claim an update was sent unless the interface confirms that action.

✅ Complete an assignment

Tap the circle beside an assignment to mark it complete. It moves from Active Assignments into Completed Assignments, where it remains counted toward progress and XP. Use Mark incomplete if needed.

📝 Add an assignment

  1. From the Dashboard, tap Quick Add.
  2. In Quick Actions, choose Add Assignment.
  3. Enter the title, subject, due date and optional notes.
  4. Tap Continue. The assignment appears in Active Assignments.

🧠 Add an exam or quiz

  1. From the Dashboard, tap Quick Add.
  2. In Quick Actions, choose Add Exam / Quiz.
  3. Enter a title, subject, date and optional notes.
  4. Tap Continue.

📅 Schedule activities & work shifts

  1. Open Schedule and tap Add activity, or use Dashboard → Quick Add → Add Schedule Activity / Job.
  2. Enter the activity and choose its category, including Job / Work Shift when appropriate.
  3. Choose the hour, minutes, and AM/PM once for each start/end time. Saved times display in 12-hour AM/PM format.
  4. Choose recurrence if needed, then save the activity.
  5. Tap an existing activity to edit or delete it.

⏱ Study Mode

Choose 10, 15, 25, 30, 45, 60 minutes or a custom duration. 25 minutes is the recommended default. Start, Pause/Resume when needed, and complete the session to earn capped XP.

👨‍👩‍👧 Parent Updates

  1. Open Parent Updates from navigation.
  2. Add contact information.
  3. Review the full message.
  4. Open the email update and review again before sending.

💾 Backup & restore

Export a backup in Settings and import it later if needed.

🔐 Privacy-first mode

Parent email is session-only by default. Use general locations instead of precise addresses.

🎓 Profile & new school year

  1. First-time setup asks for first name and grade; school and graduation date are optional.
  2. Edit these later in Settings → Student profile.
  3. Use Year in Review for an engagement-based XP celebration; grades do not determine the message.
  4. Use Start New School Year to keep the basic profile while clearing school-year planner activity.
  5. Use Complete Reset only when you want to erase the profile and return to first-time setup.
  6. Export a backup before either reset if you want to keep a copy.
